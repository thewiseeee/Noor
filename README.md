# Ayah And Reflection

create an mvp ready to be uploaded to android studio to make its apk.

The app is a Quran app with all basic features like the whole quran with translation, able to search para or surah and every aayat for any use like translation and reading or any other use, light and dark mode in settings, many fonts and styles to chose from and etc.

What should differentiate it from other Quran app is the feature of fact like daily Quran translations and aayat to motivate or just random, daily facts of way of life, daily facts about prophets, daily facts of hadith and qaida... They should be like reels and swipe up for each one.. not infinite, like statuses. make it attractive and nice to be able to use.. make it for everybody...
